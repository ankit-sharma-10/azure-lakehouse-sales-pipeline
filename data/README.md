# Sample Data

This directory contains synthetic sample data used for testing and demonstrating the Azure Lakehouse pipeline.

> [!NOTE]
> **Provenance**
> The data in `sample/synthetic_sales_data.csv` is entirely generated synthetically via Python. It mimics the schema, data types, and edge cases (e.g., NULL values, duplicates) of the original proprietary dataset, ensuring that the pipeline logic (cleansing, deduplication, aggregations) can be fully demonstrated without exposing sensitive client data.
